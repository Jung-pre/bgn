# 시안 분석 — 2026_BGN 잠실.pdf

원본: `docs/design/2026_BGN 잠실.pdf` (283MB, 7페이지)
분석 방법: PDF 페이지를 프레임 단위로 렌더해 육안 확인 + 벡터 fill 컬러 직접 추출.
(한글이 Type3 아웃라인으로 익스포트돼 있어 텍스트 복사는 불가 — 카피는 이미지에서 옮겨 적음)

---

## 1. 페이지 구성

| 페이지 | 크기(pt)     | 정체                                           |
| ------ | ------------ | ---------------------------------------------- |
| 1      | 1920 × 21975 | **PC 메인** — 1920×920 프레임 24장 스택        |
| 2      | 1920 × 920   | PC 헤더 + 히어로 단독 컷                       |
| 3      | 1160 × 3840  | 진료센터 카드 **확장(hover)** 상태 6종         |
| 4      | 375 × 17336  | **모바일 메인** — 375×812 프레임 22장 스택     |
| 5      | 524 × 520    | 진료센터 **축소** 상태 6종 (각 87px, 세로쓰기) |
| 6      | 1625 × 520   | 진료센터 기본 상태 (사진 포함, 각 260px)       |
| 7      | 1640 × 640   | 진료센터 기본 상태 (그라데이션만)              |

**중요**: 1페이지는 긴 웹페이지가 아니라 **스크롤 상태별 스토리보드**다.
프레임 24장이 실제로는 13개 섹션이다 — 히어로 하나가 GNB 상태별로 3장,
Web blog 하나가 가로 스크롤 진행 상태로 5장 차지한다.

3·5·6·7 은 서로 다른 화면이 아니라 **같은 아코디언 컴포넌트의 상태 세트**다:

```
default : 262 × 6           = 1572 (+gap) ≈ 1640  ← p6 / p7
hover   : 1160 + 87 × 5     = 1595 (+gap) ≈ 1640  ← p3 + p5
```

## 4. 타이포

시안 PDF 는 텍스트를 Type3(아웃라인)로 익스포트해서 **폰트명을 추출할 수 없다.**
국문은 Pretendard, 영문 디스플레이는 세리프(Marcellus 자리표)로 시작하되
디자이너에게 실제 지정 폰트를 확인해야 한다.

실측 크기(1920 기준 px):

| 용도            | 크기     |
| --------------- | -------- |
| 히어로 헤드라인 | 96 / 120 |
| 마퀴 디스플레이 | 108      |
| Web blog 타이틀 | 116~124  |
| 푸터 대표번호   | 92       |
| 연도 숫자       | 76~80    |
| 섹션 헤드라인   | 48~56    |
| 카드 타이틀     | 34~44    |
| 영문 아이브로우 | 26~32    |
| 본문            | 22~28    |

**섹션 헤더 공식** — 시안 전 섹션이 예외 없이 이 3단이다:

```
영문 아이브로우 (블루 26px, 세리프)
  ↓
국문 헤드라인 (48px 볼드, 일부 어절만 형광 마커)
  ↓
본문 2행 (24px, 키워드만 볼드)
```

## 5. 반복 모티프

- **마퀴** — `BGN Eyeclinic Jamsil`(히어로), `AI Precision System`(AI 섹션).
  섹션 전환 디바이더 역할. 같은 컴포넌트를 써야 한다.
- **형광 마커** — 헤드라인 일부 어절을 연블루 박스로 감쌈. AI 상담폼·히스토리에 등장.
  등장 시 좌→우 wipe 가 자연스럽다.
- **파란 원형 체크 리스트** — 히스토리 4개 시대 전부.
- **플로팅 pill** — GNB, CTA 버튼, 지점 탭이 전부 같은 radius 언어.
- **글라스 머티리얼** — 브랜드 필름 로고와 AI 상담폼 `B` 가 같은 계열. 3D 자산 재사용 대상.

## 6. 3D / 인터랙션 인벤토리

| 섹션          | 종류                                            | 구현 난이도         |
| ------------- | ----------------------------------------------- | ------------------- |
| 히어로        | 파티클 구체(수만 점) + 궤도 링 상태             | 높음                |
| 브랜드 슬로건 | 이리데슨트 리본(유리질 곡면) + 패럴랙스 3레이어 | 높음                |
| 브랜드 필름   | 유리 굴절 로고 + 반딧불 파티클 + 라이트 트레일  | 높음                |
| AI 시스템     | 홍채 스캔 / 데이터 큐브 / **3D 안구** / 바 차트 | 중 (안구만 3D 권장) |
| AI 상담       | 유리 굴절 `B`                                   | 중                  |
| 클로징        | 파티클 구체 (히어로 재사용)                     | 낮음 (재사용)       |

**권고**: 3D 씬이 5개면 프레임 예산이 감당이 안 된다.

- 히어로 ↔ 클로징은 **같은 오브젝트 재사용** (수미상관이라 디자인 의도에도 맞음)
- 브랜드 필름 ↔ AI 상담의 유리 머티리얼도 **같은 GLB 재사용**
- AI 시스템 4개 비주얼 중 3D 는 안구 하나만, 나머지는 SVG + GSAP
- 모든 씬은 `useSceneActive()` 로 화면 밖에서 `frameloop="never"`

스크롤 인터랙션:

| 종류                   | 섹션                                                  |
| ---------------------- | ----------------------------------------------------- |
| pinned 진행도 → 인덱스 | 히스토리(5스텝)                                       |
| pinned 가로 스크롤     | Web blog                                              |
| pin + UI 숨김          | 브랜드 필름                                           |
| hover 가로 아코디언    | 진료 센터                                             |
| 캐러셀                 | 의료진(8) / 진료센터(6, 모바일) / AI 스텝(4) / 이벤트 |
| 무한 마퀴              | 히어로 / AI 시스템                                    |

## 8. 확인이 필요한 것

우선순위 순.

1. **히어로 장면 2개가 캐러셀인가, 스크롤 전환인가.**
   현재는 자동 전환 캐러셀로 구현했다. 스크롤 연동이면 `usePinnedProgress` 로 바꿔야 하고,
   그러면 `brand-slogan` 섹션은 히어로에 흡수돼 삭제된다. **구조가 달라지는 결정.**

2. **영문 디스플레이 폰트.** 시안이 아웃라인이라 추출 불가. `src/app/layout.tsx` 한 곳만 고치면 된다.

3. **진료센터 명칭 통일.** 시안에 `스마일센터`(p5) / `스마일라식센터`(p3, p6) /
   `스마일라식·프로`(GNB) 3종이 혼재. 메뉴·카드·페이지 타이틀이 전부 달라진다.

4. **4개국어를 실제로 운영하는가.** 시안 언어 드롭다운이 한/영/일/중 4개다.
   국문 전용이면 지금 걷어내는 게 훨씬 싸다(middleware, `[locale]` 라우트, 사전 4벌).

5. **푸터 지도.** 시안에는 주소 텍스트만 있고 지도 임베드가 없다. 넣을지 확인.

6. **AI 섹션 데이터 비주얼의 3D 여부.** 4개를 전부 3D 로 만들면 프레임 예산 초과.

7. **의료진 8인 정보.** 도트 인디케이터가 8개인데 시안에서 이름이 읽히는 건 1명(박세광 대표원장)뿐.

8. **부산 지점 정보.** 푸터 지점 탭에 부산이 있는데 주소·진료시간이 시안에 없다.

9. **카피 오탈자 검수.** 한글이 아웃라인이라 이미지에서 옮겨 적었다. `src/shared/i18n/messages.ts` 전체 검수 필요.
