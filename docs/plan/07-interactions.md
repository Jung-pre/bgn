# 인터랙션 스펙 — 디자이너 주석 원문

Figma **Dev Mode 주석**에서 수집한 것이다. PDF 익스포트에는 나오지 않고
`get_design_context` 응답의 `data-interaction-annotations` /
`data-content-annotations` 속성으로만 나온다.

> 주석 원문은 손대지 않았다. 오타·띄어쓰기 그대로다.

## 섹션별 주석

### 히어로 — 구체 (`2:493`)

```
https://www.auremin.com/

레퍼사이트 대로 구현 필요,

로딩 화면 없이 진입 시 지구형태가 약간돌면서 등장 후 마우스 포인터에 맞춰 빛 요소가 움직이도록
```

요구사항 3가지:

1. **로딩 화면 없음** — 스플래시/프로그레스 금지. 첫 프레임부터 콘텐츠가 보여야 한다.
2. 진입 시 **지구 형태가 약간 회전하며 등장**
3. 이후 **마우스 포인터에 맞춰 빛 요소가 이동**

⚠️ Figma 안의 구체는 **사전 렌더된 PNG 2장 블렌드**다(`opacity 80` +
`mix-blend-plus-lighter opacity 40`). 3D 소스가 파일에 없다.
정적 재현은 이미지 2장으로 되지만 위 주석 요구(회전 등장 + 포인터 추종 빛)는
**못 맞춘다.** 실제 3D/WebGL 제작이 필요하다.

구현 선택지:

- (A) **파티클 포인트클라우드로 재현** — 현재 `hero-scene.tsx` 방향.
  구체 표면에 대륙 형태가 있으므로 지구 텍스처를 알파/밝기 맵으로 써서
  포인트를 분포시켜야 한다.
- (B) **PNG 2장 + WebGL 라이트 레이어** — 구체 본체는 이미지로 두고
  빛 요소만 셰이더로. 가장 싸고 시안 재현도가 가장 높다. **1순위 추천.**
- (C) 디자이너에게 3D 원본(blend/c4d/glb) 요청 — 있다면 이게 정답.
