## ★ 히어로 — 가장 중요한 발견

기획안은 히어로를 **4개 안(案)으로 제안**하고 있다.

### 히어로 1안 — 구체 → 타워 (auremin.com / brainall.kr)

```
첫 화면
AI 데이터를 상징하는 구체가 화면 중앙에서 천천히 회전하며
세계를 향한 BGN의 도약을 상징합니다.

스크롤 인터랙션
사용자가 스크롤하면 구체가 자연스럽게 사라지고,
AI 스타일의 롯데월드타워가 등장합니다.
타워는 천천히 회전하며 BGN의 성장과 미래 비전을 표현합니다.

타워 연출
빛과 선으로 이루어진 AI 스타일의 3D 타워와 데이터 네트워크 효과
```

**이게 그동안 미해결이던 질문의 답이다.**

시안의 `메인_01-02`(구체)와 `메인_02`(타워+리본)는 **캐러셀이 아니라 하나의 히어로 안에서
스크롤로 전환**되는 것이다. 구체가 사라지며 타워가 등장한다.

→ 현재 코드는 히어로를 자동 전환 캐러셀로, 타워를 `brand-slogan` 별도 섹션으로 분리해 뒀다.
**둘 다 틀렸다.** 하나의 pinned 히어로로 합쳐야 한다.

### 히어로 2안 — 블루 웨이브 + 의료진 (handhold.io)

화이트 톤 + 블루 웨이브, 메인 카피와 **의료진 이미지 병치**.
시안 `2:3008` 에 의료진 8인 컷아웃(840×200, 40px 겹침)이 있는 게 이 안의 잔재다.

### 히어로 3안 — 시네마틱 영상 + 이벤트 슬라이드 (hanwhafund.co.kr)

```
부산에서 시작해 강남, 잠실을 거쳐 세계를 향한 BGN의 도약
'150년을 내다보는 안과'
```

→ 시안의 `2:994` "BGN잠실 메인페이지 영상_2차본" 이 이 영상이다.

### 히어로 4안 — 로고 모션 그래픽 + 이벤트 슬라이드

```
빛과 선의 움직임을 활용해 BGN 로고가 하나의 오브젝트처럼 자연스럽게 완성
```

### 해석

최종 시안은 **1안(구체→타워)을 채택하고, 3안의 영상과 이벤트 슬라이드를
아래 섹션으로 내린 형태**로 보인다. 2안의 의료진 이미지도 흡수돼 있다.

**확인 필요**: 4개 안 중 무엇이 확정인지, 아니면 위 해석대로 통합인지.
히어로 구조가 통째로 달라지는 결정이다.

## 섹션2 — AI 검사시스템

```
1. 핵심 모션: 순차적 등장
여러 겹의 정보 패널(카드)들이 한 번에 나타나지 않고,
짧은 시차를 두고 '쫘라라락' 순서대로 떠오르며 배치되는 입체적인 연출

2. 상세 동작 계획
· 시작 조건: 스크롤을 내려 해당 섹션이 화면에 보일 때
· 등장 효과: 투명 → 선명, 살짝 아래에서 위로 스무스하게 올라와 제자리에 안착
```

→ Figma 주석("시간차를 두고 카드들이 배치되며")과 일치. 구현은 `useSectionReveal` 스태거로 충분하다.

## 섹션4 — 상담 예약

```
· 우측 원형 그래픽 (The AI Lens): 데이터가 융합되는 모습을
  기하학적인 선과 겹겹의 원으로 형상화
· 회전 모션: 중앙의 그래픽 요소들과 회전.
  AI가 실시간으로 데이터를 스캔·분석하는 '하이테크' 무드
```

⚠️ 기획안 목업은 **유리 다면체 + 내부 구체** 3D 오브젝트다.
그런데 **최종 시안에서는 762×762 빈 프레임 + "영상 삽입 예정"** 으로 바뀌었다.
→ **영상이 최신.** 3D 로 만들지 말 것.

## 섹션5 — 센터별 안내

```
· 부드러운 탭 전환: 마우스 스크롤을 내리거나 좌측 메뉴를 클릭할 때마다
  우측의 리스트 내용만 스무스하게 페이드되며 교체
· 리스트 호버 효과: 세부 진료 리스트에 마우스를 올리면
  글씨가 굵어지거나 밑줄이 생기며 상세 페이지로 넘어갈 수 있음을 알림
```

⚠️ 이 텍스트는 레퍼런스(cynx.io)의 동작 설명에 가깝다.
**기획안 목업은 명백히 가로 아코디언**이다 — 중앙 확장(시력교정센터) + 좌우 세로쓰기 축소
(스마일센터/백내장센터) + 우측 끝 `≡` 토글 + **하단 프로그레스 6칸 + 좌우 화살표**.

→ 아코디언이 맞다. 다만 **하단 프로그레스 바 6칸 + 화살표**는 현재 구현에 없다. 추가할 것.
`≡` 토글이 Figma 주석의 "클릭 시 이후 3개 펼침"에 해당한다.

## 섹션6 — 병원 연혁

```
· 통합 스크롤: 연도별 텍스트와 해당 이미지를 하나의 '세트'로 묶습니다.
  마우스 스크롤을 내리면 텍스트와 이미지가 엇갈림 없이
  동시에 똑같은 속도로 화면 위를 향해 흘러갑니다.
· 부드러운 등장: 새로운 연도 세트가 화면 하단에서 처음 시야에 들어올 때
  투명도 0%에서 100%로 스르륵 선명해지며 살짝 위로 떠오르듯 등장
```

⚠️ **pin 이 아니다.** "동시에 똑같은 속도로 흘러간다" = 일반 스크롤 + fade-up 등장이다.
현재 구현(pinned 5스텝 + 카드 스택 회전)보다 **훨씬 단순**하다.

다만 Figma 시안에는 카드에 `rotate 9° / skewX 2.84°` 변형이 걸려 있고
주석에 skazy.ai 참고가 붙어 있다. **어느 쪽이 최종인지 확인 필요.**
기획안 쪽이면 구현 난이도가 크게 내려간다(−2일).
