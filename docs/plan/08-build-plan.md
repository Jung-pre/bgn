## Day 0 — 차단 해제 (반나절, 지금 바로)

개발을 시작하기 전에 물어야 답이 오래 걸리는 것들이다. **먼저 던져놓고 개발을 시작**한다.

### 디자이너에게

1. **히어로 구체 3D 원본이 있는가** (blend / c4d / glb / Spline)
   → 있으면 3D 경로, 없으면 PNG+WebGL 경로. **일정이 3일 이상 갈린다.**
2. 영상 3개 납품 일정 — 브랜드 필름(1920×1080) / AI 상담 오브젝트(762×762) / Web blog 배경
3. `gradiant 1~3` 변수의 실제 정의 (MCP 로 값이 안 나옴)
4. 진료센터 명칭 통일 — `스마일센터` / `스마일라식센터` / `스마일라식∙프로`
5. 의료진 8인 정보 (이름·직함·사진)
6. 부산 지점 주소·진료시간
7. Web blog 마스크 텍스트 SVG 원본
8. **히어로 4개 안 중 무엇이 확정인가** (기획안에 1~4안이 제안돼 있다)
   - 1안 구체→타워 스크롤 전환 / 2안 블루웨이브+의료진 / 3안 시네마틱 영상 / 4안 로고 모션
   - 최종 시안은 1안 채택 + 3안 영상을 아래 섹션으로 내린 형태로 **보이지만** 확정 아님
   - **히어로 구조가 통째로 달라진다. 1순위 확인 항목.**
9. **연혁이 pin 인가 일반 스크롤인가** — 기획안은 "엇갈림 없이 동시에 같은 속도로 흘러감"(pin 아님),
   시안은 카드에 rotate/skew 변형 + skazy.ai 참고. 기획안 쪽이면 −2일

### 기획/클라이언트에게

10. 상담 신청 폼 수신 방식 (API / 메일 / 외부 폼)
11. 블로그·이벤트 데이터 출처 (CMS / 하드코딩 / 기존 API)
12. 푸터 지도 삽입 여부
13. 로그인·회원가입 실제로 만드는가 (GNB 에 있음)

### 본인 확인

14. **레퍼런스 11개 사이트 직접 열어보기** — 목록은 `docs/plan/09-brief.md` 마지막 절.
    주석이 "레퍼사이트 대로 구현 필요"라고 못 박아 뒀으므로, 재현 수준을
    **개발 전에 합의**해야 한다. 이걸 안 하면 섹션마다 재작업이 난다.

## 단계별 플랜

기간은 **작업일(1인 기준)**. 주 5일 가정.

### Phase 1 — 기반 정비 (3일)

에셋 없이도 전 섹션을 만들 수 있게 하는 공통 조각부터.

- `<VideoSlot>` — 영상 자리 컴포넌트. poster 이미지 + `<video>` 교체가 prop 하나로 되게.
  IntersectionObserver 로 화면 밖에서 `pause`. 영상 3곳이 전부 이걸 쓴다.
- `<MaskedText>` — 글자 구멍으로 배경이 비치는 처리 (`mask-image`). Web blog 용.
- Swiper 도입 — 캐러셀이 4곳(의료진/센터/AI스텝/이벤트)이라 한 번 넣으면 전부 재사용.
- `useCountUp`, `useDrawLine` — AI 카드 데이터 비주얼용 (숫자 카운트업, SVG stroke 드로잉).
- 목 데이터 레이어 — `src/shared/api/` 에 인터페이스 + 목 구현. 백엔드 확정 시 구현체만 교체.

**산출물**: 공통 컴포넌트 5종, 목 API 레이어
**의존**: 없음 ← 지금 바로 시작 가능

### Phase 2 — 전역 UI (4일)

- GNB 실구현 — 로고 SVG, 드롭다운, 스크롤 숨김, 다크 구간 대응 불필요(확인됨)
- 메가메뉴 — 우측 슬라이드 + 행 스태거, 좌측 브랜드 패널
- 언어 드롭다운 — 구조만 유지(국문 전용)
- 퀵바 팬아웃 (레퍼: the1seoul.com) + 챗봇 FAB
- 모바일 하단 고정바 5구성

**산출물**: 전 페이지 공통 크롬 완성
**의존**: 로고 SVG (Figma 에서 추출 가능 → 차단 아님)

### Phase 3 — 히어로 (구체 → 타워) (6일) ★ 최대 리스크

**기획안 확인으로 범위가 커졌다.** 구체 단독이 아니라 **구체 → 타워 스크롤 전환**이다:

```
첫 화면    구체가 중앙에서 천천히 회전
스크롤     구체가 사라지며 AI 스타일 롯데월드타워 등장, 타워도 천천히 회전
타워 연출   빛과 선으로 이루어진 3D 타워 + 데이터 네트워크 효과
```

→ `hero` 와 `brand-slogan` 을 **하나의 pinned 섹션으로 합친다.**
`usePinnedProgress` 로 진행도를 만들고 구체 opacity/scale ↔ 타워 opacity/rotate 를 크로스페이드.

시안 주석: `로딩 화면 없이 진입 시 지구형태가 약간돌면서 등장 후 마우스 포인터에 맞춰 빛 요소가 움직이도록`

분기:

- **3D 원본 있음** → GLB 로드 + 회전 인트로 + 포인터 라이트 (3일)
- **없음 (기본 가정)** → PNG 구체 2장 + WebGL 라이트 레이어 (5일)
  - 구체 본체는 시안 PNG 그대로 (재현도 100%)
  - 그 위 셰이더 캔버스로 빛 요소만. 포인터 추종 + 진입 회전은 CSS transform + 셰이더 혼합
  - 파티클 전면 재현(현재 `hero-scene.tsx`)은 **보류** — 대륙 형태까지 맞추려면 비용이 급증한다

동시에: 타이틀 글자 stagger(B/G/N 개별 노드), 마퀴, 스크롤 인디케이터, 장면 2 전환.

**⚠️ 로딩 화면 금지** — 스플래시/프로그레스를 넣으면 주석 위반이다.
`FirstFrameReady` 로 3D 만 늦게 페이드인하고 텍스트는 즉시 노출.

**산출물**: 히어로 완성 (구체는 최종본 또는 근사)
**의존**: 구체 에셋 (없으면 시안 PNG 로 진행 가능 → **차단 아님**)

### Phase 4 — 상단 섹션 5개 (6.5일)

> 브랜드 슬로건(타워)은 Phase 3 히어로에 흡수됐다.

| 섹션             |  일 | 핵심                                                                    |
| ---------------- | --: | ----------------------------------------------------------------------- |
| 브랜드 필름      | 0.5 | **영상 슬롯** + UI 전체 숨김 (`data-gnb-hide`)                          |
| 의료진           | 1.5 | 교차 이동 캐러셀 8인, 도트 8                                            |
| AI 정밀검사      | 2.5 | 헤드라인 좌→우 생성, 카드 스태거, 카드별 데이터 비주얼 (레퍼: ambiq.ai) |
| AI 상담 신청     | 1.5 | 폼 + **영상 슬롯** + 클릭 시 확대 상태(`2:1244`)                        |
| AI 브랜드 스토리 | 0.5 | 탭 3 + 영상 카드                                                        |

**의존**: 영상 2개 (플레이스홀더로 진행 가능)

### Phase 5 — 진료센터 (3일)

주석: `해당 영역 클릭시 현재 선택된 센터 이후의 3가지 영역이 펼쳐짐(모바일에선 제거)`

현재 구현(hover 1개 확장)을 버리고 재설계. 상태가 2단이다:
`기본 240×6` ↔ `확장 1120 + 축소 64×5` ↔ `+ 클릭 시 이후 3개 펼침`

기획안 목업에 **하단 프로그레스 바 6칸 + 좌우 화살표**가 있다 — 현재 구현에 없으니 추가할 것.

실측값은 `docs/plan/03-spacing-layout.md` 에 있다. 확장 카드 내부는
`backdrop-blur 10px` + 좌→우 그라데이션 + 국문 42 / 영문 24 Belleza / 본문 18.

**의존**: 센터 6종 사진 (시안에서 추출 가능)

### Phase 6 — 히스토리 (1~3일) ← 확인에 따라 갈림

**기획안**: "텍스트와 이미지가 엇갈림 없이 동시에 똑같은 속도로 흘러가고,
화면 하단에서 들어올 때 투명도 0→100 으로 살짝 위로 떠오르며 등장"
→ pin 없음. `useSectionReveal` 만으로 끝난다. **1일**

**시안**: 카드에 `rotate 9° / skewX 2.84°` 변형 + skazy.ai 참고 주석
→ pinned 5스텝 + 카드 스택 회전. **3일**

Day 0 에서 확정할 것. 기획안 쪽이면 2일 절약된다.

### Phase 7 — Web blog (4일)

가장 까다로운 구간.

- pinned 세로→가로 변환 트랙
- 배경 **영상** + `backdrop-blur 75px` + `rgba(0,114,236,0.2)`
- **마스크 텍스트** — 글자 구멍으로 영상이 비침 (`mask-image`, SVG)
- 진입 시 fade in-out 후 가로 트랙 진입
- 다크 타일 심볼 4종(스파클/클로버/4각/플라워) — 인덱스 고정, 랜덤 금지
- 블로그 **최신 3건**

**의존**: 영상 1개 + 마스크 SVG. 둘 다 없으면 정적 이미지로 근사.

### Phase 8 — 이벤트 · 클로징 · 푸터 (3일)

## 마감이 당겨지면 버릴 순서

위에서부터 버린다. 아래로 갈수록 버리면 안 되는 것.

1. AI 카드 **개별** 인터랙션 → 공통 스태거로 통일 (−1.5일)
2. 히스토리 카드 스택 회전 → 단순 크로스페이드 (−1일)
3. 브랜드 슬로건 패럴랙스 3레이어 → 정적 배경 (−1일)
4. Web blog 마스크 텍스트 → 일반 텍스트 (−1일)
5. 퀵바 팬아웃 → 단순 토글 (−0.5일)
6. 구체 포인터 추종 빛 → 진입 회전만 (−1.5일)

여기까지 6.5일 단축. **이 아래는 건드리지 말 것**:

- 반응형(Phase 9) — 모바일 트래픽이 주력인 병원 사이트다
- `prefers-reduced-motion` — 접근성 사고 위험
- 영상 지연 로딩 — 안 하면 모바일에서 사이트가 안 뜬다

## 섹션별 완료 기준 (DoD)

각 섹션은 아래를 전부 만족해야 완료로 친다.

1. PC 1920 에서 시안 스크린샷과 나란히 놓고 육안 대조 통과
2. 375 / 768 / 1024 / 1440 에서 레이아웃 붕괴 없음
3. 주석에 적힌 인터랙션이 실제로 동작 (`docs/plan/07-interactions.md` 대조)
4. `prefers-reduced-motion: reduce` 에서 콘텐츠가 **사라지지 않고** 최종 상태로 보임
5. 키보드로 모든 인터랙티브 요소 도달 가능
6. 3D/영상 포함 시 화면 밖에서 렌더/재생 정지 확인
7. `tsc` · `eslint` · `next build` · `analyze:chunk` 통과
