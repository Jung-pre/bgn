전부 Figma 노드 실측이다.

## 기준 폭

| 항목            | PC                     | 모바일                |
| --------------- | ---------------------- | --------------------- |
| 아트보드        | **1920**               | **375**               |
| 콘텐츠 컨테이너 | **1760** (좌우 **80**) | **335** (거터 **20**) |
| GNB 바          | **1840** (좌우 **40**) | 335 (거터 20)         |

> ⚠️ PDF 육안 분석 때 콘텐츠 폭을 1640/여백 140 으로 추정했었는데 **틀렸다.**
> Figma 실측은 `Container 1760 @ x=80` 이 반복 등장한다(3회). 1640 은
> 진료센터 아코디언 **컴포넌트 아트보드** 폭이지 페이지 컨테이너가 아니다.

모바일(`p4` 실측): 335 × **50**, `top 25`, radius **12**, 좌우 거터 20.

## 진료센터 아코디언

```
컨테이너 내부 폭 1600  (아트보드 1640 − padding 20 × 2)

기본  : 240 × 6                 + gap 32 × 5  = 1600  ✓
확장  : 1120 + 64 × 5           + gap 32 × 5  = 1600  ✓

카드 높이   600   (모바일 480)
카드 radius  24
카드 padding 24 / 64  (px-24 py-64)
arrow-detail 48 × 48
```

비율로 환산하면 **확장 : 축소 = 17.5 : 1**.
CSS 는 고정 px 이 아니라 `flex-grow` 비율로 구현했다 —
1440px 뷰포트에서 1120px 카드가 넘치기 때문이다.

      ├ G  118 × 144

      └ 밝은눈안과  (x=320.9)
의료진 컷아웃  840 × 200 @ (80, 575)   카드 140 × 200, x간격 100 (겹침)

→ 히어로 좌측 정렬 기준도 **80** 으로 콘텐츠 컨테이너와 동일하다.
