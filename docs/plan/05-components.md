# 공통 컴포넌트

Figma 에서 **구조가 살아 있는** 노드는 헤더와 진료센터 카드 둘뿐이다.
나머지 PC 프레임은 플랫 이미지라 개별 스펙을 얻을 수 없다.

## 1. Header (`2:2404`)

`03-spacing-layout.md` 참고. 요점:

- **불투명 흰색이 아니다.** `whitebg-90` + `backdrop-blur(25px)` + 1px 흰 보더.
  배경이 비쳐 보이는 게 의도 → solid 로 바꾸면 안 된다.
- 네비 텍스트: `pc/title/title 4` (Pretendard SemiBold 20 / 1.5 / -3%), `#242424`
- 로그인·회원가입: `pc/body/body 2` (Regular 16 / 1.5 / -3%), `#3d3d3d`
- 구분선: 1 × 12, `#a3a3a3`
- 네비 라벨 8개 (구분자가 `·` 가 아니라 **`∙` U+2219**):

  `밝은눈안과` `스마일라식∙프로` `시력교정술` `백내장∙노안`
  `드림렌즈` `안구건조증` `안종합검진` `커뮤니티센터`

- 다크 섹션 위에서도 색이 바뀌지 않는다 → shin 처럼 섹션 톤 추적 로직이 **불필요**.

## 4. 히어로 타이틀 (`2:3069`)

`B` / `G` / `N` 이 **개별 텍스트 노드**로 분리돼 있다(각 높이 144 ≈ 120px).
글자 단위 stagger 애니메이션이 디자인 의도로 보인다.
스크린리더에는 `aria-label` + `.sr-only` 로 원문을 함께 노출할 것.
